The PyEarthSuite Ecosystem
==========================

PyEarth is the core GIS and spatial foundation of the modular PyEarthSuite ecosystem:

* **pyearth** (this package): Core GIS operations, spatial toolbox, system utilities.
* `pyearthviz <https://github.com/changliao1025/pyearthviz>`_: 2D visualization with Matplotlib and Cartopy.
* `pyearthviz3d <https://github.com/changliao1025/pyearthviz3d>`_: Interactive 3D visualization using GeoVista / PyVista.
* `pyearthriver <https://github.com/changliao1025/pyearthriver>`_: River network topology and graph algorithms.
* `pyearthmesh <https://github.com/changliao1025/pyearthmesh>`_: Advanced mesh generation (lat-lon, hexagon, MPAS).
* `pyearthhelp <https://github.com/changliao1025/pyearthhelp>`_: Hydrological data retrieval (NWIS, NLDI, GSIM) and HPC execution tools.
